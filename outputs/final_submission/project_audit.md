# Final Project Audit

Audit date: 2026-10-30. This audit uses existing artifacts only; no model was
retrained and no checkpoint was modified.

## Grad-CAM audit

The original implementation selected `model.layer4[-1]`, which is a ResNet
residual block rather than a convolution. It has been corrected to select
`model.layer4[-1].conv2`, the final convolution module in ResNet18. A test now
asserts this exact target: `tests/test_p3.py`.

`GradCAM._forward_hook` stores detached activations and registers a tensor hook
on the forward output to capture gradients during backpropagation. The target
score is explicitly documented: with `class_idx=None`, Grad-CAM targets each
image's predicted class; an integer or per-image tensor can request another
class. The implementation uses channel-wise spatial-average gradient weights,
ReLU, bilinear upsampling, and per-image min/max normalization to [0, 1]. The
overlay uses a jet colormap with alpha 0.4.

The earlier nearly-dark maps were not evidence that gradients were absent:
per-image normalization still produced max values near 1, but the residual-block
hook and broad low-contrast maps made the visualization difficult to interpret.
On a held-out test batch after targeting `conv2`, CAM standard deviations were
approximately 0.18–0.30 and the maps had non-trivial regions above 0.5. This is
an implementation/visualization improvement, not evidence that the classifier
reliably focuses on the bird.

The improved sample panels are in `outputs/gradcam_improved/` (two correct and
two incorrect). They show more spatial structure, but several maps still cover
background or broad image regions. Therefore no claim is made that the model
focuses on the bird in general.
